What this tool is — and isn't

This is a lightweight foundation check. It looks at 19 common, high-value controls across five domains and gives you a directional read on posture in under an hour. It is designed to work for both a security consultant running it live in a client session, and a client running it alone without a security background.

This is not: a penetration test, a red-team engagement, a full architecture review, or a certified compliance audit (e.g. SOC 2, ISO 27001/42001 certification). The automated probes cover a small, fixed set of known attack patterns — passing them does not mean the system is free of vulnerabilities, only that it resisted these specific tests.

Framework references (NIST AI RMF, ISO/IEC 42001, MITRE ATLAS) shown throughout are indicative orientation pointers, not a certified compliance crosswalk. Verify exact clause/technique mappings against the current published standards before using them in a formal audit trail.

Guided checks

Structured yes/no-style questions you answer based on what you know (or can quickly confirm) about the system. Click "Why this matters" on any item for a plain-language explanation and what evidence would prove it.

Automated tests

Sends small, clearly-labelled test payloads to the endpoint configured in Setup and looks at what comes back. Each test proposes a suggested result based on a simple, transparent heuristic — you always confirm or override the final answer, since judging a security response often needs human context.

Reminder: requests go straight from your browser to your configured endpoint. Only run these against systems you're authorized to test.
